# Collaboration & Sponsorship

Ananas is building an open, cloud-native interoperability and benchmarking workspace for coding agents, portable skills, model routing, and reproducible software-engineering evaluation.

## Collaboration priorities
1. Portable Agent Skills adapters for Continue/Nemotron.
2. MCP integrations that improve real coding workflows.
3. Reproducible model benchmarks and cost/reliability telemetry.
4. Provider-portable LiteLLM routing and failover.
5. Secure Codespaces/GCP developer-environment automation.

## Upstream-first contribution policy
- Fix upstream when the issue belongs upstream.
- Fork only when Ananas must maintain a deliberate divergence.
- Record every external dependency in `upstream/registry.yaml`.
- Preserve license and attribution requirements.
- Prefer small, reviewable PRs backed by tests or benchmark evidence.

## Partnership targets
- NVIDIA: Agent Skills, Nemotron/NIM, NeMo Agent Toolkit, Inception/startup ecosystem.
- Continue: skill/rule/MCP interoperability and coding-agent UX.
- Vercel/skills ecosystem: portable Agent Skills distribution.
- Microsoft: skills/MCP interoperability.
- Google Cloud and GitHub: cloud developer-workspace and deployment workflows.

## What Ananas can offer partners
- Open compatibility adapters.
- Public reproducible benchmark results.
- Real-world cloud-native reference implementations.
- Bug reports and upstream patches with evidence.
- Demonstrations in demanding software-engineering workflows.

## Sponsorship readiness gate
Do not lead with a funding request. Build evidence first: working integrations, public benchmarks, upstream contributions, external users, security documentation, and measurable cost/reliability results.
